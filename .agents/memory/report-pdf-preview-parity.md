---
name: Report PDF preview parity
description: Keeps downloaded financial statements visually and structurally aligned with the in-app report preview.
---

Downloaded financial-statement PDFs must follow the same page hierarchy, comparative-column state, tables, notes, traceability, and signature presentation shown in the report preview.

**Why:** Users review and approve the preview as the expected final document; a separate text-oriented export breaks that approval contract even when the accounting values agree.

**How to apply:** Treat preview changes and PDF changes as one presentation surface. When either changes, compare rendered pages rather than validating only extracted text or raw PDF bytes.
